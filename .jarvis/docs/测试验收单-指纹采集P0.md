# 测试验收单 - 指纹采集 P0

> 逐条对应《需求规格-指纹采集P0.md》第 8 节 V1–V7。每条给出验证方式与期望，可机械判定。

## 1. 机械判据（数据库可直接判定）

| id | 判据 | 验证方式 | 期望 | 责任 |
|---|---|---|---|---|
| V1 | 族≠版本 | `select count(*) from fp_finding where version_granularity='family' and product_version is not null` | 0 | 测试 |
| V2 | 无证据不入库 | `select count(*) from fp_finding f left join fp_evidence e on e.finding_id=f.id where e.id is null` | 0 | 测试 |
| V3 | P0 零新增请求 | `select sum(req_count) from fp_scan_stat` | 0 | 测试 |
| V4 | 出厂规则全禁用 | `select count(*) from fp_rule where enabled=1` | 0 | 测试 |

## 2. 功能判据

| id | 判据 | 验证方式 | 期望 |
|---|---|---|---|
| V5 | 详情页可见 + 证据可展开 | 打开已扫资产详情页，看对应端口下的 服务名/服务版本/Web服务器/PHP版本；点「证据」展开 | 可见，含原文如 `X-Powered-By: PHP/7.4.3` |
| V6 | 扫描中闸 | 扫描中资产触发指纹解析后查 `fp_scan_stat` | req_count=0 且 skipped_reason='scan_in_progress' |
| V7 | 回滚 | `update sys_config set conf='0' where name='fp.enabled'` 后重启 | 恢复原行为，表保留 |

## 3. 单测（不依赖靶机）

| id | 用例 | 期望 |
|---|---|---|
| U1 | 解析 `Version: 3.2.3` | exact / 3.2.3 |
| U2 | 解析 CPE 行 | vendor/product/version 三件正确 |
