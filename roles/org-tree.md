# Jarvis 数字员工公司 · 组织树（v8）

## 三级蒸馏结构（每级都是该领域顶级真人，动态蒸馏+校验）

```
CEO（领域顶级大佬）
 └─ 架构师（领域架构顶级大佬）
     └─ 分析架构 → 确定技术方向
         └─ 按方向蒸馏开发角色（该方向顶级真人）
```

## 软件开发领域示例

| 层级 | 角色 | 候选真人大佬 |
|---|---|---|
| CEO | 软件领域 CEO | Linus Torvalds / Jeff Bezos / Bill Gates |
| 架构师 | 软件架构师 | Martin Fowler / Robert C. Martin / John Ousterhout |
| 开发-前端 | React/Vue 方向 | Dan Abramov / 尤雨溪 / Ryan Dahl |
| 开发-后端 | Go/服务端 | Rob Pike / Russ Cox / Kent Beck |
| 开发-数据库 | 存储方向 | Michael Stonebraker / Martin Kleppmann |
| 开发-分布式 | 系统方向 | Jeff Dean / Leslie Lamport |

## 铁律
- 每级角色必须动态蒸馏（web 查证方法论），过 jarvis_distill 校验
- 候选池是"该领域公认顶级真人"，可补充但必须真实可查证
- 蒸馏的是框架不是署名：产出只写"借鉴其方法"
