## 修掉的问题（按严重度）

| # | 问题 | 真实后果 | 修法 | 回归用例 |
|---|---|---|---|---|
| 1 | **跨站写**：`/api/jarvis/command`、`/voice`、`/tts` 都回 `access-control-allow-origin: *` | 任意网页用 `content-type: text/plain`（简单请求、无预检）就能静默驱动 31 个工具（派活/写板/跑闸/改配置）并读到结果 | 写接口加同源校验（`Origin/Referer` 的 host 必须等于请求 `Host`）+ 不再回通配 CORS；错误码 403 | 跨站 Origin 一律拒绝；同源放行 |
| 2 | **SSRF/配置注入**：语音 `baseUrl` 不校验协议 | 可写 `file:///etc/passwd`、`javascript:`、`data:`、内嵌账号 URL，TTS 代理会去请求它 | 只允许 `http/https`，禁 userinfo，错误回 400 并给原因 | 5 种非法形态都被拒；合法 URL 正常保存 |
| 3 | **项目内容跨源可读**：`/api/jarvis/{state,summary,capabilities,tools,sessions,events,voice}` 回 `*` | 任意站点能读你的任务/黑板/记忆/卡片 | 这些接口不再回通配 CORS（本页同源，不需要）；`/api/luke-jarvis/board` 旧契约保持不变 | 逐条断言无 `*` |
| 4 | **事件增量漏事件**：`/events` 把 `lastSeq`（全库最后一条）当 `since` 给 UI | 积压事件多于 `limit` 时，中间事件被静默跳过；首屏 `since=0` 拿到的是**最旧** 50 条，"最新事件"块显示的不是最新 | 服务端回 `nextSeq`（本次返回的最后一条）+ `hasMore`，新增 `tail=1` 取最新；UI 分页追平 + 首屏用 tail | 12 条事件按 5 条翻页不丢；tail 取最新 |
| 5 | **工作区错位**：`resolveWorkspace` 把 apply 期缓存排在真实会话之前；`rememberExec` 是"首次生效"；HTTP 路由吃"最近一次工具 exec" | 能力台/HTTP 命令出现"闸按 A 项目判、文件写 B 项目"；路由读到 `/tmp/.jarvis` 之类 | 重排：exec → ctx scope → **活着的**最近 exec → 缓存 → live 会话；`rememberExec` 改为最近覆盖；HTTP 路由只信 live 会话（解析不到就报 `no workspace`，不拼 `/`） | 优先级/覆盖/live-only 三组断言 |
| 6 | **能力台不显示工作区** | 用户不知道命令落在哪个项目；跨项目时出错难定位 | 能力台头部显示工作区，执行结果回填服务端确认的 `workspace`；命令按绑定 agent 的 `cwd` 落盘 | UI 静态断言 |
| 7 | **`#coreState` 被 `setText` 冲掉子节点** | 语音波形条（`.voice-ticks`）首屏后消失 | 文字拆到 `#coreStateText`，动画节点保留 | UI 静态断言 |
| 8 | **指令面没接**（原页面只会说"这条没发出去"） | "对话"是摆设，用户以为接了 | 新增 `POST /api/jarvis/chat` → 真调 `agent.followup(UserMessage)`（dsh-agent 契约：role/content/source）；成功说"已投递到会话 X 的输入队列"，**仍不伪造回答**；落 `chat` 事件可审计 | 消息形状/空/超长/无 followup/跨站/无会话 6 组断言 |

## 仍然没做的（诚实边界，不是"已对接"）

- **SSE 推送**：事件/快照仍轮询（5s 状态、3s 事件）；P1 计划换 SSE（`events.jsonl` 增量 tail）。
- **事件读取是整文件解析**：项目跑久了 `events.jsonl` 变大后单次读会变慢（P1 加偏移量索引）。
- **音频链路**：目前浏览器 Web Speech + 可配置的 OpenAI 兼容 `/audio/speech`；`instructions` 与参考音频（CosyVoice2/GPT-SoVITS 语气控制）未透传。
- **场景帧覆盖子集**：relay 只投影 employees/tasks/events/meetings 等，上游 schema 还有 conversations/decisions 等更丰富字段，未全量映射。
- **无鉴权**：接口靠"本机/反代边界"，多人共用同一端口时需加 token（P1）。
- **像素级观感未验收**：本环境无浏览器；场景 iframe、资源、主题注入有测试，但画面效果要你开一次看。
